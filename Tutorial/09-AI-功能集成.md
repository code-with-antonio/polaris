## 9.2 Inngest 简介

Inngest 是一个**事件驱动的后台任务框架**，用于处理异步操作。

### Inngest 核心概念

| 概念 | 说明 |
|------|------|
| **Event** | 触发任务的事件（可理解为"通知"） |
| **Function** | 处理事件的异步函数 |
| **Step** | 函数中的具体步骤（可重试、可追踪） |
| **Trigger** | 触发条件（事件、定时器等） |

### Inngest Client 配置

```typescript
// src/inngest/client.ts
import { Inngest } from "inngest";
import { sentryMiddleware } from "@inngest/middleware-sentry";

// 创建 Inngest 客户端
export const inngest = new Inngest({
  id: "polaris",  // 唯一标识
  middleware: [sentryMiddleware()],  // Sentry 错误追踪
});
```

## 9.3 Inngest Function 定义

### 基本结构

```typescript
import { inngest } from "@/inngest/client";

export const myFunction = inngest.createFunction(
  {
    id: "my-function",           // 函数唯一 ID
    cancelOn: [...],              // 取消条件
    onFailure: async ({ event, step }) => { /* 失败处理 */ },
  },
  {
    event: "my-event",           // 触发事件
  },
  async ({ event, step }) => {   // 处理函数
    // Step 1: 获取数据
    const data = await step.run("get-data", async () => {
      return await fetchData(event.data.id);
    });

    // Step 2: 处理数据
    const result = await step.run("process", async () => {
      return processData(data);
    });

    return { success: true, result };
  }
);
```

## 9.4 Inngest Step

Step 是函数中的可执行单元，支持重试和错误追踪。

### Step.run

```typescript
// 在 Step 中执行异步操作
const conversation = await step.run("get-conversation", async () => {
  return await convex.query(api.system.getConversationById, {
    internalKey,
    conversationId,
  });
});
```

### Step.sleep

```typescript
// 延迟执行
await step.sleep("wait-for-db-sync", "1s");
```

### Step 的特性

| 特性 | 说明 |
|------|------|
| **可重试** | 失败自动重试（可配置次数） |
| **可追踪** | 每个 Step 都有执行记录 |
| **幂等** | 重复执行不会产生副作用 |
| **状态保存** | 断电后从上次失败的 Step 恢复 |

## 9.7 工具定义

工具（Tool）是 Agent 与外部系统交互的桥梁。

### 工具结构

```typescript
import { createTool } from "@inngest/agent-kit";
import { z } from "zod";

// 创建读取文件工具
export const createReadFilesTool = ({ internalKey }) => {
  return createTool({
    name: "readFiles",
    description: "Read the content of files from the project",
    parameters: z.object({
      fileIds: z.array(z.string()).describe("Array of file IDs to read"),
    }),
    handler: async (params, { step: toolStep }) => {
      // 验证参数
      const parsed = paramsSchema.safeParse(params);
      if (!parsed.success) {
        return `Error: ${parsed.error.issues[0].message}`;
      }

      // 执行操作
      return await toolStep?.run("read-files", async () => {
        // 读取文件逻辑
        const results = [];
        for (const fileId of parsed.data.fileIds) {
          const file = await convex.query(api.system.getFileById, {...});
          if (file?.content) {
            results.push({ id: file._id, name: file.name, content: file.content });
          }
        }
        return JSON.stringify(results);
      });
    },
  });
};
```

## 9.8 消息处理流程详解

### 整体流程

```
用户发送消息
    ↓
ConversationSidebar.handleSubmit()
    ↓
POST /api/messages { conversationId, message }
    ↓
API Route 验证并发送事件
    ↓
inngest.send({ name: "message/sent", data: {...} })
    ↓
Inngest 触发 processMessage 函数
    ↓
Step 1: 获取对话信息
    ↓
Step 2: 获取历史消息
    ↓
Step 3: 生成标题（如果是新对话）
    ↓
Step 4: 创建 Agent 并运行
    ↓
Step 5: 更新消息状态为完成
    ↓
前端通过 Convex 实时订阅获取结果
```

### processMessage 完整代码解析

```typescript
async ({ event, step }) => {
  const { messageId, conversationId, projectId, message } = event.data;

  // 1. 等待数据库同步
  await step.sleep("wait-for-db-sync", "1s");

  // 2. 获取对话信息
  const conversation = await step.run("get-conversation", async () => {
    return await convex.query(api.system.getConversationById, {...});
  });

  // 3. 获取历史消息
  const recentMessages = await step.run("get-recent-messages", async () => {
    return await convex.query(api.system.getRecentMessages, {...});
  });

  // 4. 构建系统提示词（包含对话历史）
  let systemPrompt = CODING_AGENT_SYSTEM_PROMPT;
  if (contextMessages.length > 0) {
    systemPrompt += `\n\n## Previous Conversation:\n${historyText}\n\n## Current Request:`;
  }

  // 5. 生成标题（如需要）
  if (conversation.title === DEFAULT_CONVERSATION_TITLE) {
    const titleAgent = createAgent({...});
    const { output } = await titleAgent.run(message, { step });
    // 更新标题...
  }

  // 6. 创建 Agent
  const codingAgent = createAgent({
    name: "polaris",
    system: systemPrompt,
    model: anthropic({ model: "claude-opus-4-20250514" }),
    tools: [
      createListFilesTool({ internalKey, projectId }),
      createReadFilesTool({ internalKey }),
      createUpdateFileTool({ internalKey }),
      // ... 更多工具
    ],
  });

  // 7. 创建 Network
  const network = createNetwork({
    agents: [codingAgent],
    maxIter: 20,
  });

  // 8. 运行 Agent
  const result = await network.run(message);

  // 9. 提取回复
  const textMessage = result.state.results.at(-1)?.output.find(
    (m) => m.type === "text" && m.role === "assistant"
  );

  // 10. 更新消息
  await step.run("update-assistant-message", async () => {
    await convex.mutation(api.system.updateMessageContent, {
      messageId,
      content: assistantResponse,
    });
  });
}
```

### ConversationSidebar 组件

```typescript
// src/features/conversations/components/conversation-sidebar.tsx
export const ConversationSidebar = ({ projectId }) => {
  const conversationMessages = useMessages(activeConversationId);

  // 检查是否有消息正在处理
  const isProcessing = conversationMessages?.some(
    (msg) => msg.status === "processing"
  );

  // 发送消息
  const handleSubmit = async (message: PromptInputMessage) => {
    if (isProcessing && !message.text) {
      // 取消正在处理的消息
      await ky.post("/api/messages/cancel", { json: { projectId } });
      return;
    }

    // 发送新消息
    await ky.post("/api/messages", {
      json: { conversationId, message: message.text },
    });
  };

  return (
    <div>
      {/* 消息列表 */}
      <ConversationContent>
        {conversationMessages?.map((message) => (
          <Message key={message._id} from={message.role}>
            <MessageContent>
              {message.status === "processing" ? (
                <LoaderIcon className="animate-spin" />
              ) : (
                <MessageResponse>{message.content}</MessageResponse>
              )}
            </MessageContent>
          </Message>
        ))}
      </ConversationContent>

      {/* 输入框 */}
      <PromptInput onSubmit={handleSubmit}>
        {/* ... */}
      </PromptInput>
    </div>
  );
};
```

## 9.11 API Routes

### 发送消息

```typescript
// src/app/api/messages/route.ts
export async function POST(request: Request) {
  const { userId } = await auth();
  if (!userId) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

  const { conversationId, message } = requestSchema.parse(await request.json());

  // 创建用户消息
  const messageId = await convex.mutation(api.messages.send, {
    conversationId,
    message,
    role: "user",
  });

  // 发送 Inngest 事件触发处理
  await inngest.send({
    name: "message/sent",
    data: { messageId, conversationId, projectId, message },
  });

  return NextResponse.json({ success: true, messageId });
}
```

### 取消消息

```typescript
// src/app/api/messages/cancel/route.ts
export async function POST(request: Request) {
  const { userId } = await auth();
  if (!userId) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

  const { projectId } = await request.json();

  // 发送取消事件
  await inngest.send({
    name: "message/cancel",
    data: { projectId },
  });

  return NextResponse.json({ success: true });
}
```
