## 1.1 项目简介

Polaris 是一个**云端 AI IDE**（类似 Cursor），允许用户在浏览器中编写代码、预览效果，并与 AI 助手对话。它是一个功能完整的开发环境，集成了：

- **代码编辑器**（CodeMirror 6）
- **AI 助手**（Claude/Gemini）
- **实时预览**（WebContainer）
- **GitHub 集成**（Import/Export）
- **实时协作**（Convex 数据库）

### 技术栈总览

```
前端框架    →  Next.js 16 (App Router) + React 19
语言        →  TypeScript 5
样式        →  Tailwind CSS 4 + shadcn/ui
编辑器      →  CodeMirror 6
数据库      →  Convex (实时数据库)
AI          →  @ai-sdk/anthropic + @ai-sdk/google
后台任务    →  Inngest
认证        →  Clerk
终端        →  xterm.js + @webcontainer/api
状态管理    →  Zustand
```

## 1.2 技术选型理由

### 为什么选择 Next.js 16？

| 特性 | 优势 |
|------|------|
| App Router | 更灵活的路由系统，支持布局嵌套 |
| Server Components | 默认服务端渲染，减少客户端 JS |
| React 19 支持 | 支持最新的 React 特性 |
| 内置优化 | 自动代码分割、图片优化等 |

### 为什么选择 Convex？

| 特性 | 优势 |
|------|------|
| 实时订阅 | 数据变更自动推送到客户端 |
| 类型安全 | 自动生成 TypeScript 类型 |
| 简化架构 | 不需要单独的 API 层 |
| 内置 Auth | 集成认证解决方案 |

### 为什么选择 CodeMirror 6？

| 特性 | 优势 |
|------|------|
| 模块化设计 | 按需加载，减小体积 |
| 扩展机制 | 丰富的扩展生态 |
| 无障碍支持 | 内置 ARIA 支持 |
| Prosemirror 基础 | 成熟的编辑器框架 |

## 1.4 Feature-First 架构

Polaris 采用 **Feature-First（功能优先）** 架构，这是一种将相关功能组织在一起的代码组织方式。

### vs Layer-First（分层架构）

**传统 Layer-First：**
```
src/
├── components/    # 所有组件
│   ├── Button.tsx
│   ├── Dialog.tsx
│   └── ...
├── hooks/          # 所有 Hooks
├── pages/          # 所有页面
└── utils/          # 所有工具
```

**Feature-First：**
```
src/features/
├── auth/           # 认证相关的一切
│   ├── components/
│   ├── hooks/
│   └── utils/
├── projects/       # 项目相关的一切
│   ├── components/
│   ├── hooks/
│   └── inngest/
└── editor/         # 编辑器相关的一切
    ├── extensions/
    ├── hooks/
    └── store/
```

### Feature-First 的优势

1. **自包含性**：一个功能的所有代码都在同一个地方
2. **易于删除**：移除功能只需删除一个目录
3. **团队分工**：不同团队可以独立开发不同功能
4. **代码定位**：容易找到相关代码

### 共享代码的抽取时机

```typescript
// 当某个组件/hook 被多个 features 使用时，抽取到 src/components/
// 例如：Button、Dialog 被所有功能使用

// 当某个工具函数被多个 features 使用时，抽取到 src/lib/
// 例如：utils.ts 中的通用函数
```

## 1.6 核心数据模型

Polaris 使用 Convex 作为数据库，主要数据表如下：

```typescript
// convex/schema.ts

// 项目表
projects: defineTable({
  name: string,
  description: string,
  ownerId: string,        // Clerk 用户 ID
  githubRepoUrl: string,    // 关联的 GitHub 仓库
  createdAt: number,
  updatedAt: number,
}).index("by_owner", ["ownerId"]);

// 文件表
files: defineTable({
  projectId: id("projects"),
  name: string,
  type: "file" | "folder",
  content: string,         // 文件内容（对于 folder 为空）
  parentId: string | null, // 父文件夹 ID
  createdAt: number,
  updatedAt: number,
}).index("by_project", ["projectId"])
 .index("by_parent", ["parentId"])
 .index("by_project_parent", ["projectId", "parentId"]);

// 对话表
conversations: defineTable({
  projectId: id("projects"),
  createdAt: number,
  updatedAt: number,
}).index("by_project", ["projectId"]);

// 消息表
messages: defineTable({
  conversationId: id("conversations"),
  role: "user" | "assistant",
  content: string,
  createdAt: number,
}).index("by_conversation", ["conversationId"]);
```

## 1.7 应用入口

### 根布局 (`src/app/layout.tsx`)

```typescript
import type { Metadata } from "next";
import { Inter, IBM_Plex_Mono } from "next/font/google";
import { Providers } from "@/components/providers";
import "./globals.css";

const inter = Inter({ subsets: ["latin"], variable: "--font-inter" });
const ibpMono = IBM_Plex_Mono({
  subsets: ["latin"],
  weight: ["400", "500"],
  variable: "--font-mono",
});

export const metadata: Metadata = {
  title: "Polaris",
  description: "AI-powered cloud IDE",
};

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body className={`${inter.variable} ${ibpMono.variable}`}>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

### 全局 Provider (`src/components/providers.tsx`)

```typescript
"use client";

import { ClerkProvider } from "@clerk/nextjs";
import { ConvexProvider } from "convex/react";
import { ConvexReactClient } from "convex/react";
import { TooltipProvider } from "@/components/ui/tooltip";

const convex = new ConvexReactClient(process.env.NEXT_PUBLIC_CONVEX_URL!);

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <ClerkProvider>
      <ConvexProvider client={convex}>
        <TooltipProvider>{children}</TooltipProvider>
      </ConvexProvider>
    </ClerkProvider>
  );
}
```
