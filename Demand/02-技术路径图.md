### 1.1 项目脚手架
```

├── 服务器组件与客户端组件分离
```

**关键文件**：

- `next.config.ts` - Next.js 配置

### 1.2 后端即服务 (BaaS)
```
Convex
├── 实时数据库
├── 服务端函数 (query/mutation)
├── 自动类型生成
└── 权限控制
```

**关键文件**：
- `convex/schema.ts` - 数据模型定义
- `convex/_generated/` - 自动生成的类型和 API
- `convex/auth.ts` - 认证验证

### 1.3 认证系统
```
Clerk
├── 用户管理
├── OAuth 集成 (GitHub)
├── 订阅/付费计划

```

**关键文件**：
- `src/middleware.ts` - 路由保护
- `src/components/providers.tsx` - ClerkProvider 包装

## 第二阶段：核心数据层

### 2.1 数据 Schema 设计
```
convex/schema.ts
├── projects 表 - 项目元数据
├── files 表 - 文件系统
├── conversations 表 - AI 对话
└── messages 表 - 消息记录
```

### 2.2 Convex 函数实现

**项目相关** (`convex/projects.ts`)：
```
create() → 创建项目
get() → 获取用户所有项目
getById() → 获取单个项目详情
rename() → 重命名项目
updateSettings() → 更新项目设置
```

**文件相关** (`convex/files.ts`)：
```
getFiles() → 获取项目所有文件
getFolderContents() → 获取文件夹内容
createFile() / createFolder() → 创建
updateFile() → 更新内容
renameFile() → 重命名
deleteFile() → 删除（递归）
getFilePath() → 构建完整路径（用于面包屑）
```

**对话相关** (`convex/conversations.ts`)：
```
create() → 创建对话
getById() → 获取对话详情
getByProject() → 获取项目所有对话
getMessages() → 获取对话消息列表
```

### 2.3 系统级函数** (`convex/system.ts`)：
```
用于 Inngest 内部调用的辅助函数
- 验证内部密钥
- 直接读写数据
- 批量操作
```

## 第三阶段：异步任务系统

### 3.1 Inngest 事件驱动架构
```
src/inngest/client.ts
└── Inngest 客户端 (支持 Sentry 中间件)
```

### 3.2 事件类型
```
消息处理 → message/sent
GitHub 导入 → github/import.repo
GitHub 导出 → github/export.repo
取消消息 → message/cancel
取消导出 → github/export.cancel
```

### 3.3 任务函数

**AI 消息处理** (`conversations/inngest/process-message.ts`)：
```
1. 验证内部密钥
2. 获取对话和最近消息
3. 如需标题，启动标题生成 Agent
4. 启动编码 Agent（带 8 个工具）
5. 执行网络循环直到完成
6. 更新消息内容
```

**GitHub 导入** (`projects/inngest/import-github-repo.ts`)：
```
1. 使用 Octokit 克隆仓库
2. 遍历文件树
3. 批量写入 Convex 数据库
4. 更新导入状态
```

**GitHub 导出** (`projects/inngest/export-to-github.ts`)：
```
1. 创建 GitHub 仓库
2. 获取所有项目文件
3. 创建 Git  blobs
4. 创建 Tree 和 Commit
5. 更新分支引用
6. 导出状态回写
```

## 学习顺序建议

1. **先理解 Convex 数据层**（schema + query/mutation）
2. **学习 React Hooks 与 Convex 集成**（useQuery, useMutation）
3. **掌握 Inngest 异步任务**（事件驱动架构）
4. **深入 CodeMirror 编辑器扩展**
5. **理解 WebContainer 预览原理**
6. **学习 AI Agent 工具函数设计**
