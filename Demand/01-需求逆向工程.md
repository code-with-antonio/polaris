# Polaris 项目需求逆向工程分析

## 项目概述

Polaris 是一个**AI 驱动的全栈开发助手平台**，允许用户通过自然语言对话创建、编辑和管理代码项目，并提供实时预览功能。

---

## 核心用户需求

### 1. 用户认证与授权管理
- **需求**：用户需要安全地登录系统，只能访问自己的项目
- **实现**：使用 Clerk 进行身份验证，Convex 进行权限校验
- **证据**：`convex/auth.ts`、`src/features/auth/` 组件

### 2. 项目管理
- **需求**：用户可以创建、查看、重命名和管理多个代码项目
- **功能点**：
  - 创建新项目（空白项目或从 GitHub 导入）
  - 查看项目列表
  - 重命名项目
  - 导出项目到 GitHub
- **证据**：`convex/projects.ts`、`src/features/projects/`

### 3. 文件树与代码编辑
- **需求**：用户需要浏览项目文件结构并编辑代码
- **功能点**：
  - 展示文件夹层级结构
  - 创建文件/文件夹
  - 重命名文件/文件夹
  - 删除文件/文件夹
  - 代码高亮与语法支持
  - 自动保存更改
- **证据**：`convex/files.ts`、`src/features/editor/`、`src/features/projects/components/file-explorer/`

### 4. AI 对话式编程助手
- **需求**：用户可以通过自然语言让 AI 帮助编写代码
- **功能点**：
  - 多轮对话上下文保持
  - AI 自动执行文件操作（读/写/创建/删除）
  - 工具调用能力（listFiles, readFile, writeFile 等）
  - 自动生成对话标题
  - 消息处理状态跟踪
- **证据**：`src/features/conversations/inngest/process-message.ts`、8 个工具函数

### 5. 实时预览环境
- **需求**：用户可以在浏览器中实时预览代码运行效果
- **功能点**：
  - WebContainer 启动 Node.js 环境
  - 自动执行 install 和 dev 命令
  - 文件变更热更新
  - 终端输出显示
  - 可配置构建命令
- **证据**：`src/features/preview/hooks/use-webcontainer.ts`

### 6. GitHub 集成
- **需求**：用户可以从 GitHub 导入项目或将项目导出到 GitHub
- **功能点**：
  - OAuth 连接 GitHub 账号
  - 导入现有 GitHub 仓库
  - 导出项目为新 GitHub 仓库（支持公开/私有设置）
  - 异步任务处理（Inngest）
- **证据**：`src/app/api/github/`、`src/features/projects/inngest/`

### 7. 异步任务处理
- **需求**：长时间运行的任务（导入/导出/AI 处理）需要后台执行
- **功能点**：
  - 事件驱动架构
  - 任务取消支持
  - 失败回滚处理
  - 状态更新通知
- **证据**：`src/inngest/`、`src/features/*/inngest/`

### 8. 响应式 UI 与主题
- **需求**：美观、可访问的用户界面
- **功能点**：
  - 深色/浅色主题切换
  - 可折叠侧边栏
  - 命令面板（Cmd+K）
  - 通知提示
- **证据**：`src/components/ui/`、`src/components/theme-provider.tsx`

---

## 用户旅程地图

```
用户登录 → 创建/导入项目 → 浏览文件树 → 编辑代码 → 与 AI 对话获取帮助
                                            ↓
                                        查看预览 ← 保存更改
                                            ↓
                                        导出到 GitHub
```

---

## 数据模型（Convex Schema）

| 表名 | 用途 | 关键字段 |
|------|------|----------|
| `projects` | 项目元数据 | name, ownerId, settings, import/export 状态 |
| `files` | 文件/文件夹 | projectId, parentId, name, type, content, storageId |
| `conversations` | AI 对话会话 | projectId, title |
| `messages` | 对话消息 | conversationId, role, content, status |

## 技术栈总结

| 类别 | 技术 |
|------|------|
| 前端框架 | Next.js 16, React 19 |
| 后端/数据库 | Convex (Serverless Backend) |
| 认证 | Clerk |
| AI/LLM | Anthropic Claude + Inngest Agent Kit |
| 代码编辑器 | CodeMirror 6 |
| 预览环境 | WebContainer API |
| 任务队列 | Inngest |
| GitHub 集成 | Octokit |
| UI 组件 | Radix UI + shadcn/ui |
| 样式 | Tailwind CSS v4 |
| 状态管理 | Zustand |
| 错误追踪 | Sentry |
