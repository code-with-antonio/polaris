# Polaris 学习索引 - 微型需求拆解

> 本学习索引将项目功能拆解为 7 个可独立完成的微型需求，按难度递进排序。
> 每个任务包含：学习目标、核心源文件、实践练习。

学习步骤

  第一步：阅读核心文件（30 分钟）

  按顺序阅读以下文件，理解数据流：

  1. convex/schema.ts (第 5-31 行) - 数据模型定义
  2. convex/projects.ts - 后端 CRUD 函数
  3. src/features/projects/hooks/use-projects.ts - React Hooks 封装

  第二步：阅读学习指南（30 分钟）

  阅读 Demand/tasks/01-task-1.md，包含：
  - 每一步的关键知识点
  - 表格总结
  - 思考问题
  - 3 个实践练习

  第三步：代码逐行解析（30 分钟）

  阅读 Demand/tasks/01-task-1-code-annotation.md，包含：
  - 每段代码的中文注释
  - 数据流示意图
  - 关键概念总结表

  ---
  实践练习（建议 2-3 小时）

  练习 1：添加删除功能

  在 convex/projects.ts 中添加：

  export const remove = mutation({
    args: { id: v.id("projects") },
    handler: async (ctx, args) => {
      const identity = await verifyAuth(ctx);
      const project = await ctx.db.get("projects", args.id);

      if (!project || project.ownerId !== identity.subject) {
        throw new Error("Unauthorized");
      }

      await ctx.db.delete("projects", args.id);
    },
  });

  然后在 use-projects.ts 中添加对应的 hook。

  练习 2：添加项目描述字段

  1. 修改 schema 添加 description 字段
  2. 修改 create 和 rename 函数
  3. 在 UI 中显示描述
