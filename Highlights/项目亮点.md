# Polaris - 云端 AI IDE 项目亮点

> 本项目是一个类似 Cursor 的浏览器云端 IDE，用于简历项目经历展示。

---

## 项目简介

Polaris 是一个功能完整的**云端 AI IDE**，允许用户在浏览器中编写代码、预览效果，并与 AI 助手对话。集成了代码编辑、AI 辅助、实时预览、GitHub 集成等完整开发环境。

---

## 技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | Next.js 16 (App Router) + React 19 + TypeScript |
| UI 样式 | Tailwind CSS 4 + shadcn/ui + Radix UI |
| 代码编辑器 | CodeMirror 6 + 多种语言语法高亮 |
| 数据库 | Convex (实时数据库) |
| AI 能力 | Claude Sonnet 4 / Gemini 2.0 Flash + Inngest AgentKit |
| 后台任务 | Inngest |
| 认证 | Clerk + GitHub OAuth |
| 代码执行 | WebContainer API + xterm.js |
| 状态管理 | Zustand |
| 错误追踪 | Sentry |

---

## 核心亮点

### 1. 先进的 AI 集成

- **双 AI 模型支持**：Claude Sonnet 4（首选）和 Gemini 2.0 Flash（免费替代）
- **Ghost Text 实时建议**：代码编写时 AI 自动提供代码建议
- **Cmd+K 快速编辑**：选中代码+自然语言指令，AI 自动完成修改
- **AI 对话助手**：基于 Inngest AgentKit 的智能 Agent，支持文件操作
- **多轮对话上下文**：完整的对话历史管理

### 2. 专业级代码编辑器

- **多语言语法高亮**：JavaScript、TypeScript、CSS、HTML、JSON、Markdown、Python
- **代码折叠与行号**
- **括号匹配与缩进提示**
- **Minimap 代码概览**
- **多光标编辑支持**
- **自定义主题**（One Dark）

### 3. 完整文件管理系统

- **树形文件浏览器**：支持文件夹层级
- **完整的 CRUD 操作**：创建、重命名、删除文件和文件夹
- **VSCode 风格文件图标**
- **Tab 切换多文件**
- **自动保存**（带防抖）

### 4. 实时协作能力

- **Convex 实时数据库**：数据变更自动推送到所有客户端
- **乐观 UI 更新**：提升用户体验
- **多端同步**：项目数据实时同步

### 5. 后台任务处理

- **Inngest 工作流**：异步处理耗时操作
- **GitHub 导入**：异步拉取仓库代码
- **GitHub 导出**：异步创建分支和 PR
- **非阻塞 UI**：后台任务不影响前台交互

### 6. 浏览器内代码执行

- **WebContainer API**：在浏览器中运行 Node.js 代码
- **xterm.js 终端**：完整的终端模拟器
- **实时预览**：代码修改即时预览效果

### 7. GitHub 深度集成

- **一键导入**：从 GitHub 仓库导入完整项目
- **一键导出**：项目导出到 GitHub（创建 PR）
- **仓库关联**：项目与 GitHub 仓库关联管理

### 8. 工程化实践

- **Feature-First 架构**：代码组织清晰，易于维护
- **类型安全**：全程 TypeScript + Convex 自动生成类型
- **错误追踪**：Sentry 集成监控 AI 响应和应用错误
- **认证集成**：Clerk + GitHub OAuth 完整认证流程

## 数据模型

### Projects（项目表）

- name: 项目名称
- description: 项目描述
- ownerId: 所有者 ID（Clerk 用户 ID）
- githubRepoUrl: 关联的 GitHub 仓库
- createdAt / updatedAt: 时间戳

### Files（文件表）

- projectId: 所属项目
- name: 文件/文件夹名称
- type: 类型（file | folder）
- content:文件内容
- parentId: 父文件夹 ID

### Conversations（对话表）

- projectId: 所属项目
- createdAt / updatedAt: 时间戳

### Messages（消息表）

- conversationId: 所属对话
- role: 角色（user | assistant）
- content: 消息内容
